## Что это

Vetmos — клиентский мод только с визуалом: свой прицел, Target HUD, эффекты ударов, HUD-панели и настройки мира. Это **не чит**:

- мод не совершает никаких действий за игрока;
- не отправляет серверу ничего лишнего;
- не показывает ничего сверх того, что игра и так получает в ванилле.

По сути это то же, что дают Lunar или Badlion, только в своём стиле.

- Меню открывается на **правый Ctrl** (клавишу можно сменить в настройках управления). Интерфейс полностью на русском, описание модуля видно при наведении.
- **Каждая функция — отдельный модуль.** ЛКМ по модулю включает его, ПКМ (или ⚙) открывает окно настроек. В окне: вкладки групп настроек, пояснение под каждой настройкой, живое превью, поиск, копирование/вставка и «Сбросить».
- **Свой цвет:** палитра в верхней панели меню. Готовые акценты, свой цвет и градиент; всё меню перекрашивается сразу.
- **Профили:** несколько наборов настроек с быстрым переключением. Конфиг можно скопировать кодом и отправить другу («Экспорт кода» / «Импорт кода» или `.config export` / `.config import`).
- **Минималистичный дизайн:** прозрачные панели, тонкие рамки, плоские кнопки, плавные анимации и чистый шрифт Fira Sans в меню (можно вернуть пиксельный в «Интерфейсе»).
- **Кликабельные координаты в чате:** если кто-то (игрок или сервер) пишет координаты вроде `-515 64 -515`, по ним можно кликнуть, и они скопируются в буфер обмена.
- **Языки:** русский и английский (переключатель RU/EN в меню). При первом запуске показывается короткое приветствие (кнопка «?» открывает его снова).
- **Всё, что рисуется на экране, — HUD-элементы.** Их можно двигать мышкой и менять размер колёсиком в редакторе HUD или прямо из окна настроек модуля (кнопка «Переместить»).
- Настройки хранятся в папке `vetmos/` внутри папки игры (профили в `vetmos/profiles/`).

## Модули

### Бой
| Модуль | Что делает |
|---|---|
| Цифры урона | Всплывающие числа урона над противником с анимацией (крупные удары выделяются) |
| Звуки удара | Свой звук при ударе и отдельный при крите (слышишь только ты) |
| Цвет удара | Свой цвет и прозрачность подсветки сущности при ударе вместо ванильного красного |
| Частицы удара | Свои частицы при ударе и крите: тип, цвет, количество |
| Эффект убийства | Молния, вспышка частиц или звук при убийстве игрока (только у тебя на клиенте) |
| Счётчик тотемов | Сколько тотемов попнул игрок: над головой и в чате, с анимацией |

### HUD
| Модуль | Что делает |
|---|---|
| HP у прицела | Твоё здоровье рядом с прицелом (с десятыми или сердечками), поглощение отдельной строкой |
| Таргет HUD | Ник, голова, HP с плавной анимацией, броня и дистанция противника |
| Броня | Броня и предметы в руках с прочностью в %, мигает при низкой прочности |
| Эффекты | Активные эффекты с таймерами |
| Перезарядки | Кулдауны жемчуга, хоруса, тотема, щита, заряда ветра |
| Клавиши | WASD, ЛКМ/ПКМ, пробел и КПС |
| Счётчик комбо | Удары подряд |
| Низкое HP | Красная пульсирующая виньетка при низком здоровье |
| Скорборд / Боссбар / Заголовки / Сообщение над хотбаром | Ванильные элементы, которые теперь можно двигать и масштабировать в HUD-редакторе (скорборд без красных цифр, фон, выравнивание) |
| Счётчик предметов | Сколько осталось тотемов, жемчуга, гэпплов, стрел, зарядов ветра и др., с предупреждением |
| FPS / Пинг / Координаты / Направление / Скорость / Время / Биом | Инфо-элементы, каждый отдельным модулем и элементом HUD |

### Рендер
| Модуль | Что делает |
|---|---|
| Свой прицел | Крест, точка, круг или свой вариант без ванильной инверсии цвета. Чёрная обводка, цвет при наведении на игрока, индикатор атаки под прицелом, текстуры из ресурспака без инверсии |
| Анимации руки | Положение и размер предмета в руке, скорость взмаха, стиль 1.7/1.8 |
| Цвет зачарований | Цвет блеска зачарований на предметах и броне |
| Зум | Встроенный плавный зум (клавиша C, меняется в настройках модуля, не конфликтует с ванильными биндами): колёсико меняет приближение, сглаживание |
| Хитбоксы | Свой цвет и толщина хитбоксов F3+B, заливка, линия взгляда, фильтры |
| Без тряски от урона | Убирает или ослабляет наклон камеры при получении урона |
| Низкий огонь | Опускает огонь на экране, прозрачность, скрытие с огнестойкостью |
| Низкий щит | Опускает и уменьшает щит в руке |

### Мир
| Модуль | Что делает |
|---|---|
| Обводка блока | Цвет и толщина обводки выбранного блока, заливка |
| Небо и туман | Цвет неба и тумана, время суток только на клиенте |
| Граница мира | Скрыть полностью или сделать статичной (без мигания, свой цвет) |

### Инвентарь
| Модуль | Что делает |
|---|---|
| Сортировка | Сортировка на **R** (клавиша меняется в настройках) прямо в открытом инвентаре или сундуке, как в Inventory Profiles Next: одинаковые предметы сливаются в полные стаки и раскладываются по порядку (как в креативе, по названию или по ID). Сортируется та часть, над которой курсор. Хотбар не трогается (опционально). Работает обычными кликами |
| Быстрое перекладывание | Зажми Shift и ЛКМ и проведи по слотам: все предметы под курсором перекладываются в другой инвентарь |

### Клиент
| Модуль | Что делает |
|---|---|
| Интерфейс | Язык, акцентный цвет и градиент. Основной стиль чёрно-белый |
| Чат | Время у сообщений и склейка одинаковых сообщений подряд («×3») |
| Макросы | Бинд клавиши на сообщение в чат, /команду или команду Vetmos, у каждого макроса своя перезарядка |

## Команды

Команды пишутся в чат с точкой и на сервер не отправляются:

```
.toggle <модуль>                       включить/выключить
.bind <модуль> <клавиша|mouse3|none>   бинд
.binds                                 список биндов
.settings <модуль> [настройка] [значение]
.reset <модуль> | .reset bind <модуль> | .reset hud [модуль] | .reset all
.profile [list | <имя> | create <имя> | delete <имя>]
.config export | .config import [код]
.macro add <клавиша> <кд> <текст> | .macro list | .macro remove <номер> | .macro clear
.modules   .gui   .hud   .help
```

Имена модулей для команд — английские (`custom-crosshair`, `target-hud`…), их показывает `.modules`.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft **1.21.7**.
2. Положите [Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.7 в папку `mods`.
3. Скачайте `vetmos-1.3.0+1.21.7.jar` со страницы [Releases](https://github.com/qan4ur/vetmos/releases) и положите в `mods`.


## Сборка из исходников

Нужна JDK 21 (если её нет, Gradle скачает её сам):

```
gradlew build
```

Готовый jar лежит в `build/libs`. Команда `gradlew runClientGameTest` запускает автоматический тест в игре: создаёт мир, включает все модули и делает скриншоты.
